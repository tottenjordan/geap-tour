# GEMINI.md

This file provides guidance to the Gemini CLI (and other Gemini-based agents)
when working with code in this repository.

## Project Overview

GEAP Workshop: a hands-on demo of the Gemini Enterprise Agent Platform — ADK
agents with MCP tools, multi-model routing, evaluation, optimization, and
governance on Google Cloud. The domain is corporate travel and expense
management.

## Where to look

- **[CLAUDE.md](./CLAUDE.md)** — the primary agent-guidance file: common
  commands (install, test, run MCP servers, deploy, optimize, evaluate),
  architecture (the two agent topologies, MCP registration, model resolution,
  evaluation, GEPA, security layers), and key conventions. Treat it as the
  single source of truth for how this codebase is organized and operated.
- **[README.md](./README.md)** — project structure, documentation index, and
  quick start.

## Code standards

Always refer to [CODE_STANDARDS.md](./CODE_STANDARDS.md) when writing code and
making environment changes. Follow it for all git, Python tooling, and testing
conventions.
